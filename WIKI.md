# VoucherVault Wiki

## Overview
VoucherVault allows users to securely store and manage their coupon codes.

## Features
- **Secure Storage**: Coupon codes are encrypted before storage.
- **Expiry Tracking**: Track coupon expiration dates.
- **Google Login**: Secure authentication via Google Key.
- **Soft Delete**: Recover deleted coupons if needed.

## Architecture
The application follows a standard 3-tier architecture:
- **Presentation Layer**: React Frontend
- **Logic Layer**: Spring Boot Backend
- **Data Layer**: PostgreSQL Database
